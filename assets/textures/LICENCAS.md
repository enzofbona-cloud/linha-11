# Texturas

Todas as texturas desta pasta vêm do ambientCG (https://ambientcg.com) e estão
sob licença **CC0 1.0** (domínio público, uso comercial livre, sem atribuição
obrigatória). Resolução 1K, formato JPG; usamos cor, normal (OpenGL) e rugosidade.

| Pasta | Material de origem |
|---|---|
| wall | PaintedPlaster017 |
| ceiling | Plaster001 |
| floor | WoodFloor051 |
| wood | Wood066 |
| door | PaintedWood005 |
| metal | Metal032 |
| fabric | Fabric030 |
| floor_aged | WoodFloor062 (1K JPG; Ambient Occlusion not supplied) |
| wall_aged | PaintedPlaster012 (1K JPG) |
| creature_hide | Leather006 (1K JPG; mapas PBR para a pele do Ouvinte) |

Os conjuntos `floor_aged` e `wall_aged` usam os mapas Color, NormalGL e
Roughness originais; `wall_aged` também inclui Ambient Occlusion. Ambos são
CC0 e estão incluídos no jogo localmente, sem dependência de serviço externo.
Fontes: [WoodFloor062](https://ambientcg.com/view?id=WoodFloor062),
[PaintedPlaster012](https://ambientcg.com/view?id=PaintedPlaster012) e
[Leather006](https://ambientcg.com/view?id=Leather006).
